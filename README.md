# Uni-Stroke IME

一筆書きストロークで日本語と英語を入力する Android の IME（インプットメソッド）です。
1990 年代の PDA で使われた一筆書き入力方式に着想を得ています。

**入力した内容が外部へ送られることはありません。** かな漢字変換も予測変換も端末内で完結します（「ネット変換」を有効にした場合を除く）。

---

## 特徴

- **完全オフラインで動く** — 変換辞書を APK に同梱し、メモリマップで読む。圏外でも精度が変わらない。辞書は 2 層で、**コア辞書（約 8 万語）はインストール直後から使え**、より語彙の広い拡張辞書（約 22 万語）はセットアップ時に取得する
- **手書きストローク入力** — 英字・数字・記号を 1 ストロークずつ書く。画面左 2/3 が英字ゾーン、右 1/3 が数字ゾーン
- **ローマ字かな入力** — ストロークをローマ字として溜め、逐次かなへ変換
- **1 文字目からの予測変換** — 「か」と書いた時点で候補バーに「各」「彼」「過去」…が並び、「おは」で「おはよう」、「かい」で「開始」「会社」、「くだ」で「ください」が出る。予測の元は、入力履歴（よく使う語ほど上）・内蔵フレーズ辞書・端末内辞書の 3 つで、**通信はしない**。辞書の語は Mozc の語コストに「その語だけで文を始めて終えられるか」と品詞・活用形の補正を加えて並べるので、活用途中の形（「食べ」「宜しけれ」）や命令形（「食べろ」）は沈み、言い切りの形が先に来る
- **日付の候補** — 「きょう」と書くと、今日の日付が `2026/10/06`・`2026年10月6日`・`10月6日`・`10月6日(火)`・`2026-10-06`・`令和8年10月6日` の順で「今日」の次に並ぶ（候補バーでも変換中でも）。日付は端末の時計で組み、履歴には覚えない
- **音声入力** — 手書きゾーンを**長押し**すると音声入力に切り替わる。**話し終わりは自動で判定して確定**するので、終わりを知らせる操作は要らない。既定では **Android 13 以降の端末内音声認識だけ**を使うので、音声も認識結果も端末から出ない。パスワード欄では使えない
- **ボイスコマンド（ハンズフリー）** — 「エンター」「確定」「取り消し」などと言えば、文字ではなく操作として実行する。連続音声入力（既定オン）なら、1 回の長押しで「音声終了」と言うまで聞き続ける
- **書き癖の学習** — 誤認識を書き直すと訂正を覚える。8 文字だけの「書き方トレーニング」も同梱
- **折りたたみ端末対応** — 大画面ではフローティング IME として利き手側に寄り、パネル以外は透過して背面アプリを素通しする。パネル上辺のつまみをドラッグすれば置き場所を変えられる（左右は端へ吸い付き、上下は隅にマグネット／中間なら自由配置）。背面の URL 欄や送信ボタンが隠れたときは上へ逃がせばよい
- **利き手の切り替え** — 左利きではボタン列とゾーンが左右反転する
- **日本語版 / 英語版の切り替え** — 設定の「言語」で、表示と入力の動きをまとめて切り替える。英語版は英単語の予測と単語削除ボタンを持つ（[英語版](#英語版)）

## 英語版

設定 → 言語 で **日本語 / English / 端末の言語に合わせる**（既定）を選べます。
「端末の言語に合わせる」では、端末が日本語なら日本語版、それ以外は英語版になります。
切り替わるのは表示だけではなく、IME の動きもです。

| | 日本語版 | 英語版 |
| --- | --- | --- |
| 入力 | ローマ字かな + かな漢字変換（abc へ切替可） | 英字のみ |
| 候補バー | 変換候補と予測変換 | 英単語の予測（続きの補完） |
| 左上のボタン | `abc ⇄ かな` の切り替え | **単語削除**（長押しで 1 語ずつ連続） |
| リターン | 合成中は確定だけ | 確定と改行を 1 回で |

英語版の入力:

- 書いている単語は下線付きの未確定表示になり、候補バーに続きの予測が最大 10 件出る。**候補をタップすると、その単語と空白が入る**。スペースを書けば打った綴りのまま確定する（自動修正はしない）
- **アポストロフィは書かなくてよい** — `dont` で `don't`、`im` で `I'm` が先頭に出る
- 候補を確定した直後の `. , ! ? : ;` は単語へ詰めて空白をうしろへ回す（`word. `）。続けてスペースを書いても二重にならない。**直後のバックスペース 1 回で、打っていた綴りへ戻る**
- **文頭は自動で大文字**。入力欄が求めているとき（メッセージや本文の欄）だけで、ユーザー名やメールアドレスの欄では立たない。シフトを 1 回書けば取り消せる
- 予測の元は、確定した単語の履歴（最大 1,000 語・端末内）と内蔵の英語辞書（約 7.7 万語・頻度順）。**通信はしない**。パスワード・メール・URL・数値の欄では予測を出さず、シークレットタブでは単語を覚えない
- ボイスコマンドは英語の言い回し（"enter" "delete" "undo" "select all" "stop listening" など）になり、音声認識も英語で聞き取る

英語辞書は AOSP（LatinIME）の単語リストから生成しています（[ライセンス](#ライセンス)）。

## プライバシー

この IME はあなたが打つすべてを見られる位置にいます。そのうえで:

| | 既定 | 「ネット変換」を有効にした場合 |
| --- | --- | --- |
| 入力内容の送信 | **しない** | 変換したい**ひらがなの読みだけ**を送信 |
| 変換 | 端末内辞書 | 端末内辞書 + 外部変換 |
| 予測 | 入力履歴 + 内蔵フレーズ辞書 + 端末内辞書 | 左記 + 外部サジェスト |

**入力中（IME を使っているあいだ）に通信するのは、「ネット変換」を有効にした場合だけです。**

「ネット変換」を有効にしていても、次の欄では**送信しません**:

- パスワード欄・メールアドレス欄・URL 欄・数値/電話/日時欄
- シークレットタブなど、アプリが学習を拒否している欄（`IME_FLAG_NO_PERSONALIZED_LEARNING`）
- 入力欄の種類が判別できない場合（送らない側に倒しています）

送信しないもの: 確定した文章そのもの、連絡先、位置情報、端末の識別子。
入力履歴は端末内の `prediction_history.json`（最大 500 件）と、英語版では `english_history.json`（最大 1,000 語）にのみ保存され、設定画面からいつでも消せます。

初回起動時に可否を尋ね、以後は 設定 → ネット変換 でいつでも変更できます。

**Google Play 版には「ネット変換」がありません。** 入力中は一切通信せず、変換は端末内辞書だけで行います（[配布フレーバー](#配布フレーバー)）。

### 音声入力とマイク

音声入力（手書きゾーンの長押し）を使うときだけマイクを開きます。

| | 既定（端末内のみ） | 設定で「自動」にした場合 |
| --- | --- | --- |
| 音声の送信 | **しない**（端末内で認識） | 端末内認識が使えないときは端末の音声認識サービスへ渡す |
| 対応 | Android 13 以降の対応端末 | 端末に音声認識サービスがあれば動く |

- 録音するのは**長押しで始めてから終わるまで**のあいだだけで、終わったら認識器ごと破棄してマイクを手放します。終わりの判定は認識器に任せ、黙れば自動で確定します（途中でやめるときは ✕）
- マイクの許可は**初めて長押ししたとき**に尋ねます。許可しても、長押しするまで録音は始まりません
- **パスワード欄では音声入力そのものを無効にします**（端末内認識であっても、パスワードを声に出すこと自体が危ないため）
- 「自動」で端末の音声認識サービスへ渡す経路は、ネット変換と同じ基準（メール欄・URL 欄・数値欄・シークレットタブなど）でも止めます
- 「自動」で使われる音声認識サービスがどこへ音声を送るかは、そのサービスの仕様しだいです。この IME からは保証できません

設定 → 音声入力 でオフにでき、オフにすると長押しは無効になります。

### ボイスコマンド（ハンズフリー）

発話が**まるごと**次の言い回しと一致したときは、文字にせず操作として実行します。
文の一部として言った場合はそのまま入力されるので、「確定」という語自体も普通に書けます。

| 操作 | 言い回し |
| --- | --- |
| 改行／送信 | エンター・リターン・改行・送信 |
| 空白 | スペース・空白 |
| 変換 | 変換 |
| 確定 | 確定・決定 |
| 1 文字消す | 削除・消して・一文字消して・バックスペース |
| 直前の音声入力を取り消す | 取り消し・取消・取り消して |
| 全選択 | 全選択・全部選択 |
| カーソル移動 | 左・右・左へ・右へ |
| 音声入力を終える | 音声終了・終了・終わり |

**連続音声入力**（既定オン）では、1 回の長押しで「音声終了」と言うか ✕ を押すまで聞き続けます。
「話す → 自動で確定 → 次を話す」を手を使わずに続けられます。
何も話されない状態が 2 回続けば自動で終わるので、黙っているあいだにマイクが開いたままにはなりません。

最初の起動（長押し）だけは手が必要です。合図の声だけで起動する仕組み（ホットワード）は
Android がアプリに開放していないため、この IME からは実装できません。

### アプリ画面での通信

入力中とは別に、**アプリの画面（アプリ本体・設定画面）を開いたとき**は次の通信があります。
IME サービスからは実行しないので、入力中に走ることはありません。

| 用途 | 接続先 | 送るもの | 既定 |
| --- | --- | --- | --- |
| アプリの更新確認 | GitHub | 「最新版は何か」の問い合わせのみ | オン（設定でオフにできます） |
| 拡張辞書の更新確認 | GitHub | 配布マニフェストの取得のみ | オフ |

どちらも入力内容は含みません。通信する以上、接続先からは**接続元の IP アドレス**と、
要求に付く User-Agent（アプリ名）が見えます。更新確認は 1 日 1 回を上限とし、
アプリの画面を開いたときに便乗するだけで、バックグラウンドで定期的に起こすことはしません。

## 動作環境

- Android 8.0（API 26）以上
- APK 約 5.7 MB（コア辞書 2.5 MB と英語辞書 1.1 MB を含む）
- 拡張辞書を入れる場合は追加で約 6.7 MB（任意・あとから入れ替え可能）

## インストール

1. [Releases](https://github.com/makiiii-git/unistroke-ime/releases) から APK をダウンロード
2. 「提供元不明のアプリ」のインストールを許可してインストール
3. アプリを開き「IME を有効化」→ 一覧で Uni-Stroke IME をオンにする
4. 「IME を切替」で入力メソッドとして選択する

初回は「書き方トレーニング」をおすすめします。`A` `K` `X` `Y` など独特の字形があり、
8 文字練習しておくとあなたの書き方が個人テンプレートとして登録されます。

## 書き方

アプリ内の入力エリア左下 `?` ボタン、または設定画面からジェスチャー見本を表示できます。
見本は認識に使っているテンプレートそのものから描画しているので、実際の判定と一致します。
`●` が書き始め、矢印が書き終わりです。

とくに間違えやすいもの:

| 文字 | 書き方 |
| --- | --- |
| `K` | 右上から左下がりに入り、折れ角を作らずそのまま時計回りにループして右下へ抜ける（`∝` 形） |
| `X` | `K` の左右反転。左上から入り反時計回りにループして左下へ |
| `E` | ギリシャ文字 `ε`。波形（`〜` を縦に伸ばした形）でも認識します |
| `V` | `v` を書いたあと終端を右へ水平に払う（この払いが `U` との識別点） |
| `I` | 縦に近く書く。傾けると「リターン」と数値的に区別できなくなります |

## ソースからビルドする

APK を使うだけならこの節は不要です。[Releases](https://github.com/makiiii-git/unistroke-ime/releases) のものをそのままインストールしてください。

JDK 17 が必要です。`JAVA_HOME` が未設定の場合は `~/.gradle/gradle.properties` に
`org.gradle.java.home` を書いてください（リポジトリ側には環境依存のパスを置いていません）。

```bash
./gradlew assembleGithubDebug
```

出力は `app/build/outputs/apk/github/debug/app-github-debug.apk` です。デバッグ署名が付くので、そのまま端末にインストールできます。

#### 配布フレーバー

配布経路ごとにフレーバーを分けています。

| | `play` | `github` |
| --- | --- | --- |
| 配布先 | Google Play | GitHub Releases（APK・協力者向け） |
| アプリケーション ID | `io.github.makiiii_git.unistroke` | `com.unistroke.ime` |
| プレミアム機能 | 試用 5 日のあと、購入（買い切り）で解錠 | 全機能・制限なし |
| ネット変換 | なし（入力中は一切通信しない） | あり（既定オフのオプトイン） |
| アプリ本体の自己更新 | なし（更新は Play が配る） | あり |
| 署名 | アップロード鍵（配布用の鍵は Play が持つ） | release 鍵 |

ID が違うので、同じ端末に両方を入れておけます。

Play 版はアプリ 1 本で、無料版・有料版には分かれていません。プレミアム機能は
音声入力とボイスコマンド・拡張辞書・書き癖の学習です。**基本の入力（一筆書き・ローマ字かな・
コア辞書での変換）は試用期間が終わってもそのまま使えます。**

購入済みかどうかは、アプリの画面を開いたときにだけ Google Play へ問い合わせます。
IME（入力中）からは問い合わせず、結果として端末内に残した設定を読むだけです。

フレーバー固有のコードは `app/src/github`・`app/src/play` にあります。

```bash
./gradlew assemblePlayDebug      # Play 版（デバッグ）

source tools/play-env.sh         # アップロード鍵のパスワードをキーチェーンから読む
./gradlew bundlePlayRelease      # Play へ上げる App Bundle（署名済み）
```

App Bundle は `app/build/outputs/bundle/playRelease/app-play-release.aab` に出ます。
アップロード鍵はリポジトリに含めていません（`tools/play-env.sh` を参照）。

### 辞書の再生成（任意）

変換辞書はビルド済みのものを同梱しているので、通常は不要です。差し替えたい場合:

```bash
python3 tools/build_dictionary.py --fetch   # 初回のみ素材を約 93 MB ダウンロード
python3 test_dictionary.py                  # バイナリ整合の検証
python3 test_ondevice.py                    # 変換品質のスモークテスト
```

素材は `tools/mozc-src/` に置かれ、リポジトリには含めません（`.gitignore` 済み）。
詳細は [tools/README.md](tools/README.md) を参照してください。

英語版の単語辞書（`english.dic`）も同じく同梱済みです。作り直す場合:

```bash
python3 tools/build_english_dictionary.py --fetch   # 初回のみ単語リストを約 0.9 MB ダウンロード
python3 test_english.py                             # バイナリ整合と予測のスモークテスト
```

### テスト

```bash
python3 run_all.py
```

Kotlin のソースを Python で写した検証ハーネスです。認識器・ローマ字テーブル・
IME の状態機械（日本語版・英語版）・文字コード処理を、実機ビルドなしで回帰テストできます。

### リリース APK の署名

**リリース用 APK の署名は CI（GitHub Actions）で行います。** ローカルのビルドは
デバッグ署名のみで、`./gradlew assembleGithubDebug` の出力はそのまま端末に入りますが、
[Releases](https://github.com/makiiii-git/unistroke-ime/releases) に載るものとは別の署名です。

CI は署名のたびに証明書の SHA-256 指紋を
[`.github/expected-signing-cert.txt`](.github/expected-signing-cert.txt) と突き合わせ、
一致しなければリリースを中止します。署名の異なる APK を配ると、既存の利用者が
上書き更新できなくなるためです。指紋は配布済みの APK から誰でも確認できます。

```bash
apksigner verify --print-certs unistroke-ime-vX.Y.Z.apk
```

#### 署名済み APK をリリースせずに入手する

動作確認のために署名済み APK が要るときは、リリースを公開せずに取り出せます。

1. Actions の「リリース」ワークフローを **`dry_run: true`** で実行する
2. 実行が終わったら生成物を取得する

```bash
gh run download <run-id>          # release-vX.Y.Z/ に APK が入っています
adb install -r app-github-release.apk
```

`dry_run` ではビルド・署名・指紋の確認までは通常どおり行い、
リリースの作成とマニフェストの更新だけを飛ばします。
