# Uni-Stroke IME

一筆書きストロークで日本語を入力する Android の IME（インプットメソッド）です。
1990 年代の PDA で使われた一筆書き入力方式に着想を得ています。

**既定では一切通信しません。** かな漢字変換も予測変換も端末内で完結します。

---

## 特徴

- **完全オフラインで動く** — 変換辞書を APK に同梱し、メモリマップで読む。圏外でも精度が変わらない。辞書は 2 層で、**コア辞書（約 8 万語）はインストール直後から使え**、より語彙の広い拡張辞書（約 22 万語）はセットアップ時に取得する
- **手書きストローク入力** — 英字・数字・記号を 1 ストロークずつ書く。画面左 2/3 が英字ゾーン、右 1/3 が数字ゾーン
- **ローマ字かな入力** — ストロークをローマ字として溜め、逐次かなへ変換
- **書き癖の学習** — 誤認識を書き直すと訂正を覚える。8 文字だけの「書き方トレーニング」も同梱
- **折りたたみ端末対応** — 大画面ではフローティング IME として利き手側に寄り、パネル以外は透過して背面アプリを素通しする。パネル上辺のつまみをドラッグすれば置き場所を変えられる（左右は端へ吸い付き、上下は隅にマグネット／中間なら自由配置）。背面の URL 欄や送信ボタンが隠れたときは上へ逃がせばよい
- **利き手の切り替え** — 左利きではボタン列とゾーンが左右反転する

## プライバシー

この IME はあなたが打つすべてを見られる位置にいます。そのうえで:

| | 既定 | 「ネット変換」を有効にした場合 |
| --- | --- | --- |
| 通信 | **一切しない** | 変換したい**ひらがなの読みだけ**を送信 |
| 変換 | 端末内辞書 | 端末内辞書 + 外部変換 |
| 予測 | 入力履歴 + 内蔵フレーズ辞書 | 左記 + 外部サジェスト |

「ネット変換」を有効にしていても、次の欄では**送信しません**:

- パスワード欄・メールアドレス欄・URL 欄・数値/電話/日時欄
- シークレットタブなど、アプリが学習を拒否している欄（`IME_FLAG_NO_PERSONALIZED_LEARNING`）
- 入力欄の種類が判別できない場合（送らない側に倒しています）

送信しないもの: 確定した文章そのもの、連絡先、位置情報、端末の識別子。
入力履歴は端末内の `prediction_history.json`（最大 500 件）にのみ保存され、設定画面からいつでも消せます。

初回起動時に可否を尋ね、以後は 設定 → ネット変換 でいつでも変更できます。

## 動作環境

- Android 8.0（API 26）以上
- APK 約 4.6 MB（コア辞書 2.5 MB を含む）
- 拡張辞書を入れる場合は追加で約 6.7 MB（任意・あとから入れ替え可能）

## インストール

1. [Releases](https://github.com/makiiii-git/unistroke-ime/releases) から APK をダウンロード
2. 「提供元不明のアプリ」のインストールを許可してインストール
3. アプリを開き「IME を有効化」→ 一覧で Uni-Stroke IME をオンにする
4. 「IME を切替」で入力メソッドとして選択する

初回は「書き方トレーニング」をおすすめします。`A` `K` `X` `Y` など独特の字形があり、
8 文字練習しておくとあなたの書き方が個人テンプレートとして登録されます。

## 書き方

アプリ内の入力エリア左下 `?` ボタン、または設定画面からジェスチャー見本を表示できます。
見本は認識に使っているテンプレートそのものから描画しているので、実際の判定と一致します。
`●` が書き始め、矢印が書き終わりです。

とくに間違えやすいもの:

| 文字 | 書き方 |
| --- | --- |
| `K` | 右上から左下がりに入り、折れ角を作らずそのまま時計回りにループして右下へ抜ける（`∝` 形） |
| `X` | `K` の左右反転。左上から入り反時計回りにループして左下へ |
| `E` | ギリシャ文字 `ε`。波形（`〜` を縦に伸ばした形）でも認識します |
| `V` | `v` を書いたあと終端を右へ水平に払う（この払いが `U` との識別点） |
| `I` | 縦に近く書く。傾けると「リターン」と数値的に区別できなくなります |

## ビルド

```bash
./gradlew assembleDebug
```

JDK 17 が必要です。`JAVA_HOME` が未設定の場合は `~/.gradle/gradle.properties` に
`org.gradle.java.home` を書いてください（リポジトリ側には環境依存のパスを置いていません）。

### リリース用の署名

配布する APK には署名が必要です。鍵はリポジトリに置かないので、各自で作ります。

```bash
keytool -genkeypair -v -keystore release.jks -alias unistroke \
        -keyalg RSA -keysize 4096 -validity 10000
```

対話的にパスワードと氏名等を聞かれます。次に署名情報をビルドへ渡します。
**方法は3つあり、先に見つかったものが使われます。**

**方法 A: macOS キーチェーン（推奨・平文をディスクに残さない）**

一度だけ登録します。`-w` を**最後**に置くのが要点で、こう書くと対話プロンプトになり、
パスワードがシェル履歴にもプロセス一覧にも残りません。

```bash
security add-generic-password -a "$USER" -s unistroke-keystore -U -w
```

`password data for new item:` と聞かれるので入力し、確認でもう一度入力します（入力は非表示）。

以後のビルドはこれだけです。

```bash
source tools/release-env.sh
./gradlew assembleRelease
```

`tools/release-env.sh` はキーチェーンから読んで環境変数に入れるだけで、
パスワードを表示も保存もしません。ストアと鍵で違うパスワードにした場合は
スクリプト内の `UNISTROKE_KEY_PASSWORD` を分けてください。

**方法 B: Gradle プロパティ（CI 向け）**

シークレットを `ORG_GRADLE_PROJECT_unistrokeStorePassword` などの環境変数として
注入するか、`-PunistrokeStorePassword=…` で渡します。
`~/.gradle/gradle.properties`（リポジトリ外）に書く手もあります。

**方法 C: keystore.properties（手軽だが平文）**

```bash
cp keystore.properties.example keystore.properties
# エディタで storePassword / keyPassword を記入
```

いずれも設定しなくてもビルドは通ります（`app-release-unsigned.apk` になり、
何が足りないかがビルドログに出ます）。署名されると出力名が `app-release.apk` に変わります。

署名の確認:

```bash
apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
```

> **鍵を失うとアップデートを配れなくなります。** 別の鍵で署名した APK は既存インストールに
> 上書きできず、ユーザーは手動アンインストールを強いられます。`release.jks` と
> パスワードは必ずオフラインにバックアップしてください。
> `*.jks` と `keystore.properties` は `.gitignore` 済みです。

### 辞書の再生成

同梱済みなので通常は不要です。差し替えたい場合:

```bash
python3 tools/build_dictionary.py --fetch   # 初回のみ素材を約 93 MB ダウンロード
python3 test_dictionary.py                  # バイナリ整合の検証
python3 test_ondevice.py                    # 変換品質のスモークテスト
```

素材は `tools/mozc-src/` に置かれ、リポジトリには含めません（`.gitignore` 済み）。
詳細は [tools/README.md](tools/README.md) を参照してください。

### 検証

```bash
python3 run_all.py
```

Kotlin のソースを Python で写した検証ハーネスです。認識器・ローマ字テーブル・
IME の状態機械・文字コード処理を、実機ビルドなしで回帰テストできます。
