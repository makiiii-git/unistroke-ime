Uni-Stroke IME プライバシーポリシー

本ポリシーは、Androidアプリ「Uni-Stroke IME」（以下「本アプリ」）における利用者情報の取り扱いを定めるものです。

1. 本アプリの機能

本アプリは、一筆書きのストロークで文字を入力する日本語入力アプリ（IME）です。かな漢字変換・予測変換・手書き認識は、いずれも端末内で処理します。

入力アプリは、利用者が入力するすべての文字を扱う位置にあります。本アプリは入力した内容を開発者へ送信しません。Google Play 版は、入力中に通信を行いません。

2. 収集する情報と利用目的

2.1 端末内でのみ扱う情報（外部送信なし）

  • 入力した文字・ストローク：端末内で認識・変換し、入力先のアプリへ渡します。開発者のサーバー等への送信はありません。
  • 入力履歴（予測変換用）：確定した語句を最大500件、端末内にのみ保存し、予測候補の表示に使用します。設定画面からいつでも消去できます。パスワード欄や、アプリが学習を拒否している欄（シークレットタブ等）の入力は保存しません。
  • 書き癖の学習データ：利用者のストロークの形を端末内にのみ保存し、認識精度の向上に使用します。設定画面から文字単位または全体を消去できます。
  • 音声入力（任意）：利用者が手書きゾーンを長押しして開始したあいだだけマイクを使用します。既定では端末内の音声認識のみを使用し、音声および認識結果は端末の外へ出ません。本アプリが音声を録音・保存することはありません。パスワード欄では音声入力を無効にします。
  • アプリ設定・試用期間の情報：動作設定、試用期間の開始日時、購入済みかどうかを端末内にのみ保存します。

上記の情報は、Android のバックアップ機能を有効にしている場合、利用者自身の Google アカウントのバックアップに含まれることがあります。これは Google による処理であり、開発者はその内容にアクセスできません。

2.2 第三者サービスに送信される情報

  • 音声認識サービス（任意・既定はオフ）：利用者が音声入力の設定を「自動」に切り替えた場合のみ、端末内の音声認識が使えないときに、端末にインストールされている音声認識サービス（Google 等）へ音声を渡します。そのサービスでの音声の取り扱いは、各提供者のプライバシーポリシーに従います。
  • アプリ内課金（Google Play）：プレミアムの購入と、購入済みかどうかの確認は Google Play が処理します。確認は本アプリの画面を開いたときにのみ行い、入力中には行いません。開発者がクレジットカード番号等の決済情報にアクセスすることはありません。詳細は Googleのプライバシーポリシーをご確認ください。
  • 拡張辞書の取得・更新の確認（GitHub）：利用者が拡張辞書の取得を選んだとき、および更新の自動確認を有効にしている場合（既定はオフ）に本アプリの画面を開いたとき、GitHub へアクセスします。送信するのは辞書ファイルの要求のみで、入力内容は含みません。この際、IPアドレス等の接続情報が GitHub により処理されます。
  • GitHub で配布しているバージョンのみの機能：次の2つは Google Play 版にはありません。
    • ネット変換（任意・既定はオフ）：利用者が設定で有効にした場合のみ、変換したい「ひらがなの読み」だけを Google の変換サービスへ送信します。パスワード欄・メールアドレス欄・URL欄・数値欄等では送信しません。
    • アプリ本体の更新の確認：更新確認のため GitHub API へアクセスします。Google Play 版の更新は Google Play が行います。

3. 開発者による情報収集

開発者は、独自のサーバー等で利用者の個人情報を収集・保存することはありません。広告の表示、アクセス解析、クラッシュレポートの送信も行っていません。

4. 情報の第三者提供

開発者が利用者の情報を第三者に販売・提供することはありません（上記2.2の各サービスによる処理を除く）。

5. 情報の削除

入力履歴と書き癖の学習データは、本アプリの設定画面から消去できます。本アプリをアンインストールすると、端末内に保存したすべての情報が消去されます。

6. お子様のプライバシー

本アプリは特定の年齢層を対象としたものではなく、開発者が児童の個人情報を意図的に収集することはありません。

7. ポリシーの変更

本ポリシーを変更する場合は、本ページで告知します。重要な変更がある場合は、アプリの更新情報等でもお知らせします。

8. お問い合わせ

本ポリシーに関するお問い合わせは、GitHubリポジトリのIssueからお願いします。
